# claude-code-workflows

Inspired by [dgalarza/claude-code-workflows](https://github.com/dgalarza/claude-code-workflows).

## Plugins

| Plugin | Description |
| --- | --- |
| [conventional-commits](plugins/conventional-commits) | Skill for writing git commit messages that follow the [Conventional Commits](https://www.conventionalcommits.org) specification. |
| [branch-and-pr](plugins/branch-and-pr) | Skills for naming git branches and opening GitHub PRs with Conventional-Commits-style titles. |
| [handle-linear-issue](plugins/handle-linear-issue) | Skill that takes a Linear issue from fetch to open PR. |
